Profile Insight 是一款面向外贸销售、海外商务拓展、招聘和投资调研人员的客户研究工具。
在 LinkedIn 或 X 用户主页点击 Profile Insight，插件会读取当前主页的公开资料和近期公开动态，并使用您自行配置的大模型 API 生成结构化分析结果。
主要功能：
• 支持 LinkedIn 个人主页和公司主页
• 支持 X（Twitter）用户主页
• 自动收集并分析最多 100 条公开动态
• 提炼客户职业画像和近期关注主题
• 识别合作、招聘、采购、发布等商业信号
• 推荐适合作为沟通切入点的原动态
• 同时显示对方时区和您的本地时间
• 生成 LinkedIn 私信、X 私信、Cold Email 和跟进话术
• 本地保存分析历史，支持随时清理数据  
免费使用，自带 API
Profile Insight 不提供收费模型服务。您需要配置自己的 Gemini、DeepSeek 或其他 OpenAI Compatible API。
这样可以让您：
• 自由选择模型服务商
• 自己控制模型使用费用
• 随时更换模型和接口地址
• 无需将 API Key 提交给插件开发者  
隐私与数据处理
• API Key、设置和分析历史保存在您的浏览器本地
• 插件开发者不运营数据中转服务器
• 公开主页资料和动态只会发送给您自行配置的大模型服务
• 数据处理同时受所选模型服务商的隐私政策约束
• 插件不会收集密码、登录 Cookie 或私人消息
• 您可以在设置页面清除 API Key、历史记录和全部本地数据  
使用方法
安装 Profile Insight  
打开插件设置页面  
配置大模型 API Key、接口地址和模型名称  
打开 LinkedIn 或 X 用户主页  
点击页面中的“Profile Insight”按钮  
选择分析目的并等待结果
使用提醒
分析结果仅基于公开信息和 AI 推断，可能存在遗漏或偏差，请在联系客户前自行核实。请仅分析您有权处理的公开资料，不要将结果用于判断敏感属性或作出自动化高风险决策。
Profile Insight 旨在帮助您减少整理公开信息的时间，少一点盲目群发，多一点真正与对方相关的沟通。
