# 这个插件免费，但为什么要配置自己的 AI API？

## 备选标题

- 3 分钟配置 Gemini/DeepSeek API 使用这个插件
- 不收月费的 AI 插件，是怎么工作的？

## 正文

Profile Insight 没有内置收费套餐，插件免费，模型费用由使用者自己的 API 账户承担。

这样设计有三个原因：

第一，我不需要运营一个保存客户资料的中转服务器。

第二，使用者可以自己选择 Gemini、DeepSeek 或其他 OpenAI Compatible 服务。

第三，模型价格或可用性变化时，不需要等插件更新。

配置方法：

1. 打开插件设置。
2. 选择模型服务商。
3. 填写 API Key、接口地址和模型名称。
4. 点击连接测试。
5. 返回 LinkedIn 或 X 主页开始分析。

API Key 会保存在当前浏览器本地，不会提交给插件开发者。但主页公开资料和动态会发送给你选择的模型服务，所以还需要遵守对应服务商的隐私政策。

几个安全提醒：

- 不要把 API Key 发给别人，也不要在截图中露出完整 Key。
- 建议为这个工具单独创建 Key，并设置使用额度。
- 如果 Key 曾经公开出现，请立即撤销并重新生成。
- 只分析你有权处理的公开信息。

如果遇到 404，通常是 Base URL 或模型名称不匹配；如果提示 high demand，通常是模型暂时拥堵，可以稍后重试或切换模型。
