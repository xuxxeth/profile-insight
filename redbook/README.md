## 截图规范

- 画布建议使用 3:4 竖图。
- API Key、邮箱、私信、头像和不方便公开的客户身份必须打码。
- 每张图片只表达一个重点，正文过长时局部截取。
- 产品截图统一使用紫蓝色描边和箭头标注重点。
- 发布前将文中的「内测获取方式」替换为实际方式。
