Profile Insight

隐私政策

生效日期：2026 年 9 月 16 日

Profile Insight（以下简称“本扩展”）用于分析用户主动选择的 LinkedIn 和 X 公开主页及动态，并通过用户自行配置的大模型 API 生成客户画像、商业信号和个性化沟通建议。 本政策说明本扩展访问哪些数据、如何使用这些数据，以及用户如何管理自己的数据。

1. 本扩展访问的数据

  • 当前 LinkedIn 或 X 页面公开展示的姓名、用户名、简介及职业资料；
  • 当前页面公开展示的动态内容、发布时间及相关互动信息；
  • 用户主动填写的大模型 API Key、接口地址、模型名称及扩展设置；
  • 大模型返回的分析结果，以及用户选择保存在本地的分析历史。

本扩展不会读取或收集账号密码、身份验证 Cookie、私人消息、支付信息，或未在当前页面公开展示的资料。

2. 数据用途

上述数据仅用于：

  • 收集用户主动要求分析的公开主页资料与公开动态；
  • 将必要内容发送至用户自行选择并配置的大模型服务进行分析；
  • 展示画像、商业信号、活跃时间和沟通建议；
  • 在浏览器本地保存用户设置与分析历史。

本扩展不会将这些数据用于广告、信用评估、数据经纪、用户数据销售，或与扩展单一用途无关的活动。

3. 数据存储与传输

  • API Key、设置和分析历史通过 Chrome Storage 保存在用户浏览器本地；
  • 开发者不运营用于接收或存储这些数据的中转服务器；
  • 用户主动发起分析后，必要的公开资料和动态将直接发送至用户配置的大模型 API；
  • 模型服务商对数据的处理和保留受该服务商的条款与隐私政策约束。

4. 数据共享与披露

除完成用户主动请求的分析而向用户所选模型服务商传输必要数据外，本扩展不会出售、出租或向其他第三方共享用户数据。 法律要求或为保障安全而必须披露的情形除外。

5. 数据保留与删除

设置和分析历史保留在当前浏览器中，直至用户主动删除、清除扩展数据或卸载扩展。 用户可随时在本扩展的设置页面清除 API Key、分析历史或全部本地数据。

6. Chrome Web Store Limited Use

Profile Insight 对从 Google API 获取的信息的使用和传输，将遵守 Chrome Web Store 用户数据政策， 包括其中的 Limited Use 要求。
  • 仅将用户数据用于提供或改进用户可见且由用户主动请求的核心功能；
  • 不会将用户数据用于个性化广告；
  • 不会将用户数据出售给广告平台、数据经纪商或其他信息转售方；
  • 不会将用户数据用于信用评估、贷款或其他无关用途；
  • 除获得明确同意、安全调查、遵守法律或数据已汇总并匿名化等政策允许的情形外，不允许人工读取用户数据。

7. 用户的选择与责任

用户可以选择是否发起分析、使用哪个模型服务商，以及是否保留分析历史。 用户应仅处理其有权使用的公开信息，并在使用 AI 分析结果前自行核实其准确性。

8. 政策更新

本政策可能随扩展功能、法律或平台政策变化而更新。更新后的版本将在本页面公布，并修改生效日期。

9. 联系方式

如对本隐私政策有疑问，请通过 GitHub Issues 联系开发者。

Profile Insight

Privacy Policy

Effective date: September 16, 2026

Profile Insight (the “Extension”) analyzes public LinkedIn and X profiles and posts selected by the user. It uses an AI model API configured by the user to generate profile summaries, business signals, and personalized outreach suggestions.

1. Data the Extension Accesses

  • Names, usernames, bios, and professional information publicly displayed on the current LinkedIn or X page;
  • Public posts, timestamps, and related engagement information displayed on the current page;
  • AI API keys, endpoint URLs, model names, and settings entered by the user;
  • AI-generated results and analysis history that the user chooses to store locally.

The Extension does not read or collect passwords, authentication cookies, private messages, payment information, or information that is not publicly displayed on the current page.

2. How Data Is Used

Data is used only to:

  • Collect public profile information and posts that the user explicitly requests to analyze;
  • Send the necessary content to the AI service selected and configured by the user;
  • Display profile insights, business signals, active times, and outreach suggestions;
  • Store settings and analysis history locally in the browser.

Data is not used for advertising, credit assessment, data brokerage, sale of user data, or any purpose unrelated to the Extension's single purpose.

3. Storage and Transmission

  • API keys, settings, and analysis history are stored locally using Chrome Storage;
  • The developer does not operate an intermediary server that receives or stores this data;
  • When the user starts an analysis, required public content is sent directly to the AI API configured by the user;
  • Processing and retention by an AI provider are governed by that provider's terms and privacy policy.

4. Sharing and Disclosure

The Extension does not sell, rent, or share user data with third parties, except for transmitting necessary data to the AI provider selected by the user to complete a requested analysis, or where required by law or security needs.

5. Retention and Deletion

Settings and analysis history remain in the current browser until the user deletes them, clears extension data, or uninstalls the Extension. Users can clear API keys, history, or all local data from the settings page at any time.

6. Chrome Web Store Limited Use

Profile Insight's use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
  • User data is used only to provide or improve user-facing features explicitly requested by the user;
  • User data is not used for personalized advertising;
  • User data is not sold to advertising platforms, data brokers, or information resellers;
  • User data is not used for creditworthiness, lending, or unrelated purposes;
  • Human access is prohibited except with explicit consent or where allowed for security, legal compliance, or aggregated and anonymized internal operations.

7. User Choice and Responsibility

Users choose whether to run an analysis, which AI provider to use, and whether to retain analysis history. Users should process only public information they are authorized to use and independently verify AI-generated results.

8. Changes to This Policy

This policy may be updated when the Extension, applicable law, or platform requirements change. Updates will be posted on this page with a revised effective date.

9. Contact

For privacy questions, contact the developer through GitHub Issues.
